# Leandro Locsin Exhibit

A virtual exhibit on Leandro V. Locsin, National Artist for Architecture (1990).

## Pages

| File | Contents |
| --- | --- |
| `index.html` | Introduction, basic information, why Locsin is important, fun facts |
| `biography.html` | Early life, Zóbel and Ayala, career timeline, accolades |
| `works.html` | Five featured works with analysis, Expo '70 pavilion, more from the gallery |
| `philosophy.html` | Five pillars, bahay kubo comparison, materials, art theory |
| `legacy.html` | Legacy, nation-building, heritage conservation, project information |
| `style.css` | Shared look for every page |

`draft.html` is the original design draft. It is no longer linked and can be deleted.
